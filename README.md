# Madrigal — Frontend‑прототип аналитической платформы

Frontend‑прототип аналитической платформы для визуализации данных и демонстрации возможностей ИИ‑модуля. Разработан в рамках учебного кейса от компании Madrigal по брифу для B2B‑аудитории (гос. и корпоративные заказчики).

> ⚠️ **Важно:** Это frontend‑прототип (без бэкенда и реального ИИ). Реализованы все требования брифа на уровне клиентского кода: адаптив, интерактив, формы с валидацией, mock‑данные и UX‑сценарии.

| Требование из брифа | Моё решение и реализация |
| --- | --- |
| **Адаптивный дизайн (desktop + mobile, 390×844 px)** | Реализовал адаптивную вёрстку на CSS Grid/Flex. SCSS‑переменные и брейкпоинты обеспечивают корректное отображение на мобильных и десктопных версиях (в т.ч. проект first‑mobile). Проверено на viewport 390×844 и 1440×1100. |
| **Единая UX/UI‑концепция (landing + dashboard)** | Интегрировал дизайн‑макет в код: переиспользуемые компоненты (карточки, CTA, таблицы) согласованы между landing и dashboard. Стили и дизайн‑система предоставлены партнёром по проекту. |
| **Dashboard: графики, таблицы, карточки, фильтры, статистика** | Собрал Dashboard из компонентов (`DashboardWelcome`, `DashboardChart`, `Selector`). Для демонстрации UX использованы mock‑данные, позволяющие показать сценарии фильтрации и пересчёта статистики без бэкенда. |
| **Интерактивные элементы (переключение блоков)** | Реализовал условный рендеринг: `DashboardChart` показывается только по взаимодействию с иконкой — это снижает нагрузку и ускоряет загрузку. Анимации раскрытия реализованы через CSS (`max-height` + `opacity`). |
| **Landing page: описание, преимущества, сценарии, CTA, блок ИИ** | Сверстал и интегрировал блоки landing page по макету. Блок ИИ‑модуля реализован как UI‑заглушка для демонстрации будущего функционала. |

## 🚀 Что решает проект

- Убирает ручной расчёт стоимости проектов и построение графиков в Excel.
- Даёт менеджеру быстрый способ собрать отчёт по периодам, регионам и суммам.
- Показывает статистику в удобном виде (3 колонки + график) с плавными анимациями появления.

---

## 🧩 Функционал

- **Калькулятор стоимости** — расчёт на основе выбранных параметров.
- **Панель статистики** — отображение данных по периодам/регионам/суммам.
- **Интерактивные фильтры** — три зависимых селекта (период, сумма, регион) с кастомной анимацией раскрытия.
- **Условный рендеринг** — тяжёлые блоки (например, график) подгружаются только по взаимодействию.
- **Адаптивная вёрстка** — корректное отображение на мобильных и десктопе (в т.ч. проект `first-mobile`).

## 💡 Ключевые инженерные решения

### Next.js и гидратация
- Разделение на серверные и клиентские компоненты (`'use client'`).
- Устранены ошибки гидратации при инициализации сторонних библиотек и манипуляциях с DOM.

### Кастомизация `choices.js`
- Реализована кастомная анимация раскрытия списка через CSS (`max-height` + `opacity`) вместо стандартного поведения библиотеки.
- Пустые/заглушечные опции визуально отображаются, но программно отключены для выбора (`pointer-events: none`, `opacity: 0.6`).
- DOM‑структура сохранена, чтобы не ломать анимации.

### TypeScript и работа со сторонними библиотеками
- Компоненты спроектированы с чётким разделением логики и UI.

### Адаптивная вёрстка и UI
- Адаптивная сетка на CSS Grid/Flex для трёх колонок статистики.
- Кастомные формы: input, range slider (ползунок), кнопки — под дизайн‑макет.
- Микро‑анимации и каскадное появление блоков с разной задержкой.

## 📂 Структура проекта

- `src/app/` — страницы и роутинг (Next.js App Router).
- `src/components/` — переиспользуемые компоненты:
  - `Selector` — кастомные селекты на базе `choices.js`.
  - `DashboardWelcome`, `DashboardChart` — блоки дашборда.
  - `CustomInput`, `AnimatedSection` — кастомные формы и анимации.
- `src/styles/` — SCSS‑файлы, глобальные стили и миксины.
